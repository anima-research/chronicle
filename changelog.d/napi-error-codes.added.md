- **Error codes:** every error the Node binding throws for chronicle now carries `code`, one of the values of the new `ErrorCode` enum, such as `BranchNotFound`, `Locked` or `StoreClosed`. Its message is unchanged. Branch on `error.code` rather than on message text: a code keeps its name across releases. An error raised before a call reaches chronicle, such as for an argument of the wrong type, keeps napi's own code (`StringExpected`, `InvalidArg`) or has none.
